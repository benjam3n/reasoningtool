# Individual Analysis

**Input**: $ARGUMENTS

---

## Step 1: Identify the Individual

Who is the person at the center of this analysis?

```
INDIVIDUAL: [Name, role, or archetype]
CONTEXT: [Situation they're in]
GOAL: [What they're trying to achieve]
```

If $ARGUMENTS doesn't specify an individual, define the most likely person affected.

---

## Step 2: Map Personal Resources

What does this individual have to work with?

```
SKILLS & KNOWLEDGE:
- [Relevant skill/expertise 1]
- [Relevant skill/expertise 2]

ASSETS & ACCESS:
- [Resource 1: time, money, tools, connections]
- [Resource 2]

AUTHORITY & INFLUENCE:
- [What they can decide unilaterally]
- [Where they need permission or buy-in]
```

---

## Step 3: Identify Constraints

What limits this individual's action?

```
HARD CONSTRAINTS (cannot change):
- [Constraint 1]
- [Constraint 2]

SOFT CONSTRAINTS (difficult but possible to change):
- [Constraint 1]
- [Constraint 2]

SELF-IMPOSED CONSTRAINTS (beliefs, habits, assumptions):
- [Constraint 1]
- [Constraint 2]
```

Flag self-imposed constraints that may not be real limitations.

---

## Step 4: Assess Solo Capability

What can this individual accomplish alone?

```
CAN DO ALONE:
- [Action 1] — because [reason]
- [Action 2] — because [reason]

CANNOT DO ALONE:
- [Action 1] — needs [what's missing]
- [Action 2] — needs [what's missing]

COULD DO ALONE BUT SHOULDN'T:
- [Action 1] — better to [alternative] because [reason]
```

---

## Step 5: Identify Leverage Points

Where does this individual have the most impact per unit of effort?

```
HIGHEST LEVERAGE ACTIONS:
1. [Action] — impact: [what changes], effort: [low/medium/high]
2. [Action] — impact: [what changes], effort: [low/medium/high]
3. [Action] — impact: [what changes], effort: [low/medium/high]

HELP NEEDED:
- [Area where help is needed] — from [who/what]
- [Area where help is needed] — from [who/what]
```

---

## Step 6: Optimize for Agency

Recommend a path that maximizes what the individual can control.

```
RECOMMENDED PATH:
1. [First action — something they can do today]
2. [Second action — builds on first]
3. [Third action — extends reach]

AUTONOMY SCORE: [How much of this plan depends on others: high/medium/low autonomy]
KEY DEPENDENCY: [The single biggest thing outside their control]
```
