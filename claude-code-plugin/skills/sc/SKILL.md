# SC - Skill Creation

**Input**: $ARGUMENTS

---

## Focus

System-level skill creation process.
Different from `/cs`, which creates or updates a specific skill.

## Steps

1. Define creation objective and volume target.
2. Define schema, naming, and quality gate.
3. Define generation and review pipeline.
4. Define validation and publish criteria.

## Output

Skill creation system blueprint.
