# UF - Useful For

**Input**: $ARGUMENTS

---

## Steps

1. Identify target skill or method.
2. List best-fit use cases.
3. List weak-fit and failure cases.
4. List adjacent alternatives and switch conditions.

## Output

```text
TARGET: ...
USEFUL_FOR:
1. ...
2. ...
LIMITS:
1. ...
ALTERNATIVES:
- /skill-id - use when ...
```
