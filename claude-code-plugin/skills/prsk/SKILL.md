name: "prsk - Products"
description: Procedure for analyzing products or offerings. Identifies the user and their need, evaluates fit, compares against alternatives, and finds improvement opportunities.
---

# Products

**Input**: $ARGUMENTS

---

## Step 1: Identify the Product

```
PRODUCT: [Name or description of the product/offering]
TYPE: [Physical product / software / service / content / process / other]
STAGE: [Concept / prototype / launched / mature]
```

---

## Step 2: Identify the User and Need

```
PRIMARY USER: [Who uses this product]
USER CONTEXT: [When and where they use it]

THE NEED:
- Before this product: [How the user solves the problem today]
- Pain level: [How much the current solution hurts — low/medium/high]
- Frequency: [How often the need arises]

JOB TO BE DONE: [In one sentence, what the user "hires" this product to do]
```

---

## Step 3: Assess Product-Need Fit

```
HOW WELL DOES IT MEET THE NEED?

CORE FUNCTIONALITY:
- [Function 1]: meets need? [fully / partially / poorly]
- [Function 2]: meets need? [fully / partially / poorly]

USER EXPERIENCE:
- Ease of adoption: [easy / moderate / difficult]
- Ease of use: [easy / moderate / difficult]
- Reliability: [high / moderate / low]

FIT RATING: [Strong fit / Moderate fit / Weak fit / No fit]
REASONING: [1-2 sentences]
```

---

## Step 4: Evaluate Against Alternatives

```
ALTERNATIVES:
1. [Alternative] — better at: [what], worse at: [what]
2. [Alternative] — better at: [what], worse at: [what]
3. [Do nothing] — what happens if the user just lives with the problem

COMPETITIVE POSITION:
- This product wins when: [condition]
- This product loses when: [condition]
- Unique advantage: [what no alternative offers]
```

---

## Step 5: Identify Strengths and Weaknesses

```
STRENGTHS:
1. [Strength] — why it matters to the user: [reason]
2. [Strength] — why it matters to the user: [reason]

WEAKNESSES:
1. [Weakness] — impact on user: [how it hurts them]
2. [Weakness] — impact on user: [how it hurts them]

HIDDEN STRENGTHS (underappreciated):
- [Strength the market or user doesn't yet recognize]

HIDDEN WEAKNESSES (not yet painful):
- [Weakness that will matter more over time]
```

---

## Step 6: Improvement Opportunities and Market Fit

```
IMPROVEMENT PRIORITIES:
1. [Improvement] — effort: [low/medium/high], impact: [low/medium/high]
2. [Improvement] — effort: [low/medium/high], impact: [low/medium/high]
3. [Improvement] — effort: [low/medium/high], impact: [low/medium/high]

MARKET FIT ASSESSMENT:
- Target market size: [small niche / growing segment / large market]
- Willingness to pay: [high / moderate / low / unknown]
- Timing: [too early / right time / late]

VERDICT: [Strong product / Needs work / Pivot needed / Wrong market]
SINGLE MOST IMPORTANT THING TO DO: [one action]
```
