# CODEX STRICT EXECUTION CONTRACT (PCE)

1. Step order is mandatory:
   - Step 1: Classify input
   - Step 2: Surface hidden claims
   - Step 3: Analyze by type
   - Step 4: Synthesize
   - Step 5: Recommend action
2. No Step 4 or Step 5 content before Step 1-3 are visible.
3. Hidden claims must be explicit and numbered (`H#`).
4. Highest-VOI hidden claim must be tested with:
   - `ASSUME RIGHT`
   - `ASSUME WRONG`
5. No generic advice blocks.
6. Every action line must include verification criteria.
7. If classification is uncertain:
   - `INCOMPLETE PCE: unclear input type. Requesting clarification.`
