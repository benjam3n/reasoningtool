## Output

Ask Claude to analyze a decision and you'll get a reasonable-sounding answer. But the reasoning path is improvised — different every time, shaped by whatever phrasing you happened to use. There's no guarantee it checked for hidden assumptions, weighed tradeoffs systematically, or considered what it might be missing.

Reasoningtool is 592 structured thinking skills that plug into Claude Code. Each skill is a defined procedure: a sequence of steps, checks, and criteria that Claude follows instead of improvising. Type `/decide` and Claude walks through option mapping, criteria definition, tradeoff analysis, and failure modes. Type `/rca` and it runs root cause analysis with specific diagnostic gates. Type `/w` and it writes against an explicit quality hierarchy — upstream criteria first, downstream polish after.

The skills cover analysis, decisions, problem-solving, writing, planning, research, validation, and creativity. Category routers like `/claim`, `/diagnose`, and `/search` classify your input and route to the right skill automatically. You don't need to know which of the 592 procedures fits — describe what you're working on and the router picks.

The difference is repeatable structure. A freeform prompt produces whatever Claude assembles in the moment. A skill produces a defined reasoning path — one you can inspect, critique, and improve. The thinking becomes a process, not a guess.

Browse the full collection at reasoningtool.com.
