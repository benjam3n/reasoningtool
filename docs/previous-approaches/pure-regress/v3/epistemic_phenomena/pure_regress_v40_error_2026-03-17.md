# Recursive Causal Interrogation: Error

WHAT THIS CONCEPT COVERS:
What it means to be wrong. The difference between error and ignorance. Whether error requires a norm to deviate from. Productive error. Whether you can know you're in error while being in it. The relationship between error and truth. Systematic error vs. random error. Whether error is eliminable.
