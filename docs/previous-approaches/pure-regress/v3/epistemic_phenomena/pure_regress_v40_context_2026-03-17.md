# Recursive Causal Interrogation: Context

WHAT THIS CONCEPT COVERS:
What context is and how it determines meaning. Whether anything can be understood without context. Whether context has boundaries. The context of context (infinite regress). How context shifts meaning. Whether removing context destroys meaning or reveals essence. The relationship between text and context.
